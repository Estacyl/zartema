# ADR 0002: Explicit scope for initial member renaming

Status: initial implementation. This describes the intended contract and lists validation still required; it is not a release-readiness claim.

The initial transformation renames explicitly selected private static methods only after reading every physical class in the input archive. The default configuration keeps names. A caller must affirm that the selected names are not used by reflection, JNI, external configuration, instrumentation, serialization protocols, or other name-sensitive consumers not represented by the artifact; this is an assumption, not a fact established by analysis. Keep rules always override selection. Public and protected API, constructors, class initializers, native methods, and unresolved or unsupported cases are preserved or cause a diagnostic refusal.

ASM class-file visitors are the emission authority. Build one collision-free mapping before editing any class; apply it across all classes, method handles and bootstrap arguments. The implementation retains the original input and rejects changes to signed or digest-bearing archives. The CLI checks ASM structural/basic data flow and performs a non-initializing classpath load on the running JVM with `-Xverify:all` for staged input and output before publishing. Configurable target runtimes, module-layer validation, and a behavioral gate remain required. Unknown attributes may contain unmodelled names and must not be silently rewritten as if understood. Multi-release archives require consistent treatment of all variants and are excluded until that policy is implemented and tested. WALA and SootUp are analysis evidence, not complete reflection or semantic proofs.

Validation must include structural checks, loading and execution under `-Xverify:all`, differential output/exception/effect tests on targeted fixtures, mapping and stack-trace tests, reproducibility, and explicit skipped or failed cases. Stack traces do not contain method descriptors; a mapping must include complete method-name inventory for participating classes and refuse ambiguous reverse translations. Finite tests demonstrate behavior only in their stated envelope.
