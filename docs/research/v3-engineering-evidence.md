## M04 — reduce archive payload copying

## M06 — JVM load-gate review in progress

- Main-agent direct reads: V3 `jvm-verifier-expert/SKILL.md`, `VERIFIER_REFERENCE.md` sections 1–2 and 12, `VERIFICATION_FAILURES.md` section 4, `binary-validation/SKILL.md`, `BINARY_VALIDATION.md` section 1, and `VALIDATION_CHECKLISTS.md` sections 1–3. Applied constraints: preserve separate structural, target-JVM, and behavioral evidence; test both positive and negative cases; do not treat loader acceptance as a proof of every runtime action.
- Primary-source check: Java SE 21 `Class.forName(String, boolean, ClassLoader)` documents that `initialize=false` avoids initialization, while JVMS 21 section 5.4.3 describes symbolic resolution that can fail at use. A non-initializing load gate therefore cannot establish full linkage, initialization, or behavior. See https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Class.html#forName(java.lang.String,boolean,java.lang.ClassLoader) and https://docs.oracle.com/javase/specs/jvms/se21/html/jvms-5.html#jvms-5.4.3 . OBA reference statements and illustrative API details are not treated as substitutes for pinned API checks or specification requirements.
